# Unlimited Cloth

Unlimited Cloth is a free desktop program for Windows and Linux that makes GTA V freemode clothing and tattoos ready for FiveM. You can import garments or whole addon packs, fix them in the studio, try them on the animated freemode ped, and build a finished resource and .zip. Every file it writes is read back and checked.

- **Website and guide:** https://asarayja.github.io/unlimited-cloth-releases/
- **Download:** [Releases](https://github.com/asarayja/unlimited-cloth-releases/releases): `Unlimited-Cloth-Setup-<version>.exe` (Windows), `unlimited-cloth_<version>_amd64.deb` and `Unlimited-Cloth-<version>-x86_64.AppImage` (Linux)
- **Support:** the Unlimited Discord, https://discord.gg/uaASPkghXu

This repository holds the releases and the website (`docs/`, served by GitHub Pages). It does not hold the source code.
