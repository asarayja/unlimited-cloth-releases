    FiveM clothing and tattoos, ready to stream

    Unlimited Cloth makes GTA V freemode clothing and tattoos ready for FiveM. Import garments or whole addon packs, fix them in the studio, try them on the animated freemode ped and build a finished resource and .zip. Every file it writes is read back and checked.

    Download 1.0.0Getting startedDiscord

    No browser tab, no network port, no Blender, Python or CodeWalker needed. Made by Unlimited Reforge.

    What it does

    One program for the whole job, from loose files to a resource you can ensure.

    Clothing pack builder

    Components and props for mp_m_freemode_01 and mp_f_freemode_01, numbered for you, checked against the game's limits and written as fxmanifest.lua, stream/, .ymt and shop .meta, plus a .zip.

    Studio fix tools

    Copy weights from the body, push out of the body, fit and shrinkwrap, LODs, shaders, props, hair alternates, heels, cloth physics and texture tools. Every job can be undone.

    3D preview and animations

    The freemode ped with skin and your garments, 31 poses and animations, and Show clipping, which marks in red where the body comes through, how deep and at which bone.

    Tattoo builder

    PNG in, 512×512 DXT5 .ytd out. Place each tattoo per zone and per body in 3D or in the UV square, and get the overlay XML and ready lists for qb, esx and illenium-appearance.

    Safe with your files

    Fix jobs work on a copy in the project folder, so your original is never changed. Nothing is ever deleted for good: an old build goes to the system trash.

    Projects and languages

    Plain JSON projects (.ucloth) with relative paths that open on both Windows and Linux, autosave for crash recovery, undo and redo. The program speaks 12 languages.

    Install

    Windows

    1. Run Unlimited-Cloth-Setup-1.0.0.exe.
    2. Pick the install folder. Desktop and Start menu shortcuts are made.
    3. Uninstall later under Settings → Apps.
    "Windows protected your PC" / unknown publisher. The installer is signed with Unlimited Reforge's own certificate, which Windows does not know yet, so Microsoft SmartScreen may stop it the first time. Click More info, check that the file is the one from the release page, then click Run anyway.

    Linux

    .deb (Debian, Ubuntu and similar):

    sudo apt install ./unlimited-cloth_1.0.0_amd64.deb

    AppImage: make it executable and run it.

    chmod +x Unlimited-Cloth-1.0.0-x86_64.AppImage
./Unlimited-Cloth-1.0.0-x86_64.AppImage
    If the AppImage does not start on Ubuntu 22.04 or newer, install FUSE 2: sudo apt install libfuse2 (libfuse2t64 on 24.04).

    Where things are kept

    Settings, autosave and your own peds: %APPDATA%\Unlimited Cloth on Windows, ~/.config/Unlimited Cloth on Linux. Built resources go to Documents/Unlimited Cloth/build unless you choose another folder.

    Getting started

    1 · First-run setup

    The program starts in English and walks you through language, preferences, folders, peds and the defaults for new projects. You can skip it and run it again from ? → Run setup again.

    2 · Try it with test content

    Press Test garments on the Garments tab. You get a test top for each body and a cap for both, made by the program itself, so you can try every tool before you use your own files.

    3 · Import your garments

    + Import files takes .ydd, .ytd, .yld, Sollumz/CodeWalker .ydd.xml, .glb, .obj, .blend and .png. Folder / pack takes a whole folder or an existing addon pack.

    4 · Body, slot and textures

    For each garment choose the body (male, female or both), the component or prop slot and up to 26 texture variants (a–z). A ! in the list means something is still missing.

    5 · Check, then build

    On the Build tab press Check (plan) to see every file, number and limit before anything is written. Then press Build everything. The result is read back and checked.

    6 · On the server

    Copy the resource folders to resources/ and add them to server.cfg. Try a new pack on a test server before you put it on a live one.

    ensure my_clothes
ensure my_tattoos

    Clothing builder

    The Garments tab holds the list; the Build tab writes the resource.

    Numbers

    • The order in the list is the number: empty means the next free number in that slot.
    • A fixed number keeps saved outfits pointing at the same garment. If two garments ask for the same number, the first keeps it and the other gets the next free one, and the plan says so.
    • Past 255 drawables of one kind the rest go into a second collection (<collection>2).
    • A gap below the highest number is filled with an invisible dummy, because the game reads 000 upwards.

    Limits it checks

    • 255 drawables per slot and body, 26 textures (a–z) per garment.
    • Ped streaming slots for the server's game build.
    • Shop entries, file name length (under 128 bytes), lower-case names.
    • A garment without a slot, a body or a texture is a fault and is never guessed.

    What is written

    fxmanifest.lua, stream/ with the models, textures and cloth physics, one .ymt and one shop .meta per body, first-person models (_1.ydd), hair swaps (pedalternatevariations.meta), heel heights, and a .zip of the folder.

    Rebuilding an existing pack

    Import a built pack with Folder / pack to rename its collection or join packs. Flags, audio profiles, heel heights, prop hair, hair swaps and the collection name come back from its .ymt and .meta files.

    Tattoos

    Make and place

    • + Tattoo (PNG): each picture becomes a 512×512 DXT5 .ytd. A ready .ytd works too; the texture inside gets the tattoo's Id in the build.
    • Choose the body zone, then place the tattoo separately on the male and the female body: in 3D on the ped, or in the UV square (drag to move, mouse wheel to resize).
    • The Id is the hash name. When it is empty, the file name is used.

    What is written

    • The overlay XML and fxmanifest.lua with PED_OVERLAY_FILE.
    • Optional shop_tattoo.meta (only the base game's tattoo shop reads it).
    • Optional Menu lists in exports/: qb (AllTattoos.json), esx (Config.TattooList) and illenium-appearance. Newer illenium-appearance versions find the tattoos in the overlay file by themselves, so that list is off by default.
    Give the tattoo resource its own name. The program refuses to build if the tattoo and clothing resources would land in the same folder, because building one would move the other to the trash.

    subdir_file_mapping

    The Build tab has a subdir_file_mapping checkbox. When it is on, the clothing resource's fxmanifest.lua gets this line:

    dependencies { '/policy:subdir_file_mapping' }
    • Off is the default. With the line, a server that does not have the policy refuses to start the resource at all.
    • Without the line, a server that lacks the policy loads the pack and shows no clothes, with nothing in the console. A server with 10 slots or fewer gets the policy automatically; above that it comes with an Element Club Argentum (or higher) subscription.
    • Turn it on when your server has more than 10 slots and has the policy, so a missing policy shows up as a clear start error instead of invisible clothes. Leave it off on a server with 10 slots or fewer.
    • The build plan reminds you when it is off. Whether the line is needed has not been proven in game yet, so test on your own server.

    FAQ

    Is it free?

    Yes. Unlimited Cloth is free and open under the MIT licence, made by Unlimited Reforge.

    Do I need GTA V, Blender or CodeWalker?

    No. The program reads and writes the game formats itself, and the freemode peds for the preview come with it. On the Peds tab you can use files from your own game instead (optional).

    Which clothing menus does it work with?

    The clothing resource is a normal addon pack, so any menu that reads addon clothing shows it. For tattoos the program writes lists for qb, esx and illenium-appearance. Check the field names against your version of the menu.

    Will it change my original files?

    No. Fix jobs work on a copy in the project folder, and anything in the way (an old build, for example) goes to the system trash. Nothing is deleted for good.

    My clothes do not show in game
    • Check how many slots the server has and the subdir_file_mapping policy.
    • Make sure the resource is started (ensure) and that the server's game build is the one chosen on the Build tab.
    • Use Check an existing pack… on the Build tab to read the folder back.
    Why does Windows warn about an unknown publisher?

    The installer is signed with Unlimited Reforge's own certificate, not one bought from a certificate authority, so Windows does not know the publisher yet. See Install for how to get past SmartScreen.

    Where do I get help?

    Questions, bugs and ideas go to the Unlimited Discord. The program has no e-mail address.
