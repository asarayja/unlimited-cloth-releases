FiveM clothing and tattoos, ready to streamFiveM-klær og tatoveringer, klare til å strømmes

Unlimited Cloth makes GTA V freemode clothing and tattoos ready for FiveM. Import garments or whole addon packs, fix them in the studio, try them on the animated freemode ped and build a finished resource and .zip. Every file it writes is read back and checked.Unlimited Cloth gjør klær og tatoveringer for GTA V sine freemode-peds klare for FiveM. Importer plagg eller hele addon-pakker, fiks dem i studioet, prøv dem på den animerte freemode-pedden og bygg en ferdig ressurs og .zip. Hver fil programmet skriver, leses inn igjen og sjekkes.

What it doesHva det gjør

One program for the whole job, from loose files to a resource you can ensure.Ett program for hele jobben, fra løse filer til en ressurs du kan ensure.

Clothing pack builderPakkebygger for klær

Components and props for mp_m_freemode_01 and mp_f_freemode_01, numbered for you, checked against the game's limits and written as fxmanifest.lua, stream/, .ymt and shop .meta, plus a .zip.

Komponenter og props for mp_m_freemode_01 og mp_f_freemode_01, nummerert for deg, sjekket mot spillets grenser og skrevet som fxmanifest.lua, stream/, .ymt og shop-.meta, pluss en .zip.

Studio fix toolsFiksverktøy i studioet

Copy weights from the body, push out of the body, fit and shrinkwrap, LODs, shaders, props, hair alternates, heels, cloth physics and texture tools. Every job is undoable.

Kopier vekter fra kroppen, press ut av kroppen, tilpass og krymp, LOD-er, shadere, props, hår-alternativ, hæler, kledefysikk og teksturverktøy. Alle jobber kan angres.

3D preview and animations3D-visning og animasjoner

The freemode ped with skin and your garments, 31 poses and animations, and "Show clipping" marks in red where the body comes through, with how deep and at which bone.

Freemode-pedden med hud og plaggene dine, 31 stillinger og animasjoner, og «Vis klipping» markerer i rødt hvor kroppen stikker gjennom, hvor dypt og ved hvilket bein.

Tattoo builderTatoveringsbygger

PNG in, 512×512 DXT5 .ytd out. Place each tattoo per zone and per body in 3D or in the UV square, and get the overlay XML and ready lists for qb, esx and illenium-appearance.

PNG inn, 512×512 DXT5 .ytd ut. Plasser hver tatovering per sone og per kropp i 3D eller i UV-ruta, og få overlay-XML og ferdige lister for qb, esx og illenium-appearance.

Safe with your filesTrygt for filene dine

Fix jobs work on a copy in the project folder, so your original is never changed. Nothing is ever deleted for good: an old build goes to the system trash.

Fiksjobber jobber på en kopi i prosjektmappa, så originalen endres aldri. Ingenting slettes for godt: et gammelt bygg havner i papirkurven.

Projects and languagesProsjekter og språk

Plain JSON projects (.ucloth) with relative paths that open on both Windows and Linux, autosave for crash recovery, undo and redo. The program speaks 12 languages.

Prosjekter i vanlig JSON (.ucloth) med relative stier som åpnes på både Windows og Linux, autolagring ved krasj, angre og gjør om. Programmet har 12 språk.

Getting startedKom i gang

1 · First-run setupFørstegangsoppsett

The program starts in English and walks you through language, preferences, folders, peds and the defaults for new projects. You can skip it and run it again from ? → Run setup again.

Programmet starter på engelsk og tar deg gjennom språk, innstillinger, mapper, peds og standardvalg for nye prosjekter. Du kan hoppe over det og kjøre det igjen fra ? → Kjør oppsett på nytt.

2 · Try it with test contentPrøv med testinnhold

Press Test garments on the Garments tab. You get a test top for each body and a cap for both, made by the program itself, so you can try every tool before you use your own files.

Trykk Test garments på Plagg-fanen. Da får du en testoverdel for hver kropp og en caps for begge, laget av programmet selv, så du kan prøve alle verktøyene før du bruker egne filer.

3 · Import your garmentsImporter plaggene dine

+ Import files takes .ydd, .ytd, .yld, Sollumz/CodeWalker .ydd.xml, .glb, .obj, .blend and .png. Folder / pack takes a whole folder or an existing addon pack.

+ Import files tar .ydd, .ytd, .yld, Sollumz/CodeWalker .ydd.xml, .glb, .obj, .blend og .png. Folder / pack tar en hel mappe eller en eksisterende addon-pakke.

4 · Body, slot and texturesKropp, plass og teksturer

For each garment choose the body (male, female or both), the component or prop slot and up to 26 texture variants (a–z). A ! in the list means something is still missing.

Velg kropp (mann, kvinne eller begge), komponent- eller prop-plass og opptil 26 teksturvarianter (a–z) for hvert plagg. Et ! i lista betyr at noe fortsatt mangler.

5 · Check, then buildSjekk, og bygg

On the Build tab press Check (plan) to see every file, number and limit before anything is written. Then Build everything. The result is read back and checked.

På Bygg-fanen trykker du Check (plan) for å se alle filer, numre og grenser før noe skrives. Deretter Build everything. Resultatet leses inn igjen og sjekkes.

6 · On the serverPå serveren

Copy the resource folders to resources/ and add them to server.cfg. Try a new pack on a test server before you put it on a live one.

Kopier ressursmappene til resources/ og legg dem til i server.cfg. Prøv en ny pakke på en testserver før du legger den på en ekte server.

ensure my_clothes
ensure my_tattoos

Clothing builderKlesbyggeren

The Garments tab holds the list; the Build tab writes the resource.Plagg-fanen har lista, og Bygg-fanen skriver ressursen.

NumbersNumre

  • The order in the list is the number: empty means the next free number in that slot.
  • A fixed number keeps saved outfits pointing at the same garment. If two garments ask for the same number, the first keeps it and the other gets the next free one, and the plan says so.
  • Past 255 drawables of one kind the rest go into a second collection (<collection>2).
  • A gap below the highest number is filled with an invisible dummy, because the game reads 000 upwards.
  • Rekkefølgen i lista er nummeret: tomt betyr neste ledige nummer på den plassen.
  • Et fast nummer gjør at lagrede antrekk peker på det samme plagget. Hvis to plagg vil ha samme nummer, beholder det første det, og det andre får neste ledige. Planen sier fra.
  • Over 255 drawables av én type havner resten i en ny samling (<samling>2).
  • Et hull under det høyeste nummeret fylles med en usynlig dummy, fordi spillet leser fra 000 og oppover.

Limits it checksGrenser den sjekker

  • 255 drawables per slot and body, 26 textures (a–z) per garment.
  • Ped streaming slots for the server's game build.
  • Shop entries, file name length (under 128 bytes), lower-case names.
  • A garment without a slot, a body or a texture is a fault, never guessed.
  • 255 drawables per plass og kropp, 26 teksturer (a–z) per plagg.
  • Ped-strømmingsplasser for serverens game build.
  • Butikkoppføringer, lengden på filnavn (under 128 byte) og små bokstaver.
  • Et plagg uten plass, kropp eller tekstur er en feil og blir aldri gjettet.

What is writtenHva som skrives

fxmanifest.lua, stream/ with the models, textures and cloth physics, one .ymt and one shop .meta per body, first-person models (_1.ydd), hair swaps (pedalternatevariations.meta), heel heights, and a .zip of the folder.

fxmanifest.lua, stream/ med modeller, teksturer og kledefysikk, én .ymt og én shop-.meta per kropp, førstepersonsmodeller (_1.ydd), hair swaps (pedalternatevariations.meta), hælhøyder og en .zip av mappa.

Rebuilding an existing packBygge en eksisterende pakke på nytt

Import a built pack with Folder / pack to rename its collection or join packs. Flags, audio profiles, heel heights, prop hair, hair swaps and the collection name come back from its .ymt and .meta files.

Importer en bygd pakke med Folder / pack for å gi samlingen nytt navn eller slå sammen pakker. Flagg, lydprofiler, hælhøyder, prop-hår, hair swaps og samlingsnavnet hentes fra pakkens .ymt- og .meta-filer.

TattoosTatoveringer

Make and placeLag og plasser

  • + Tattoo (PNG): each picture becomes a 512×512 DXT5 .ytd. A ready .ytd works too; its texture is renamed to the tattoo's Id in the build.
  • Choose the body zone, then place it separately on the male and the female body: in 3D on the ped, or in the UV square (drag to move, mouse wheel to resize).
  • The Id is the hash name. When it is empty, the file name is used.
  • + Tattoo (PNG): hvert bilde blir en 512×512 DXT5 .ytd. En ferdig .ytd går også. Teksturen i den får tatoveringens Id i bygget.
  • Velg kroppssone og plasser den hver for seg på mann og kvinne: i 3D på pedden, eller i UV-ruta (dra for å flytte, musehjulet for å endre størrelse).
  • Id-en er hash-navnet. Er den tom, brukes filnavnet.

What is writtenHva som skrives

  • The overlay XML and fxmanifest.lua with PED_OVERLAY_FILE.
  • Optional shop_tattoo.meta (only the base game tattoo shop reads it).
  • Optional menu lists in exports/: qb (AllTattoos.json), esx (Config.TattooList) and illenium-appearance. Newer illenium-appearance versions find the tattoos in the overlay file by themselves, so that list is off by default.
  • Overlay-XML og fxmanifest.lua med PED_OVERLAY_FILE.
  • Valgfri shop_tattoo.meta (bare spillets egen tatoveringsbutikk leser den).
  • Valgfrie menylister i exports/: qb (AllTattoos.json), esx (Config.TattooList) og illenium-appearance. Nyere versjoner av illenium-appearance finner tatoveringene selv i overlay-fila, så den lista er av som standard.

subdir_file_mapping

The Build tab has a subdir_file_mapping checkbox. When it is on, the clothing resource's fxmanifest.lua gets:

Bygg-fanen har en avkrysningsboks for subdir_file_mapping. Når den er på, får klesressursens fxmanifest.lua denne linjen:

dependencies { '/policy:subdir_file_mapping' }
  • Off is the default. With the line, a server that does not have the policy refuses to start the resource at all.
  • Without the line, a server that lacks the policy loads the pack and shows no clothes, with nothing in the console. A server with 10 slots or fewer gets the policy automatically; above that it comes with an Element Club Argentum (or higher) subscription.
  • Turn it on when your server has more than 10 slots and has the policy, so a missing policy shows up as a clear start error instead of invisible clothes. Leave it off on a server with 10 slots or fewer.
  • The build plan reminds you when it is off. Whether the line is needed has not been proven in game yet, so test on your own server.
  • Av er standard. Med linjen nekter en server uten policyen å starte ressursen i det hele tatt.
  • Uten linjen laster en server uten policyen pakken, men viser ingen klær, og ingenting står i konsollen. En server med 10 plasser eller færre får policyen automatisk. Over det følger den med et Element Club Argentum-abonnement (eller høyere).
  • Slå den på når serveren har mer enn 10 plasser og har policyen, slik at en manglende policy gir en tydelig startfeil i stedet for usynlige klær. La den være av på en server med 10 plasser eller færre.
  • Byggeplanen minner deg på det når den er av. Om linjen trengs, er ikke bevist i spillet ennå, så test på din egen server.

FAQ

Is it free?Er det gratis?

Yes. Unlimited Cloth is free and open under the MIT licence, made by Unlimited Reforge.

Ja. Unlimited Cloth er gratis og åpent under MIT-lisensen, laget av Unlimited Reforge.

Do I need GTA V, Blender or CodeWalker?Trenger jeg GTA V, Blender eller CodeWalker?

No. The program reads and writes the game formats itself, and the freemode peds for the preview come with it. On the Peds tab you can use files from your own game instead (optional).

Nei. Programmet leser og skriver spillformatene selv, og freemode-peddene til visningen følger med. På Peds-fanen kan du bruke filer fra ditt eget spill i stedet (valgfritt).

Which clothing menus does it work with?Hvilke klesmenyer virker det med?

The clothing resource is a normal addon pack, so any menu that reads addon clothing shows it. For tattoos the program writes lists for qb, esx and illenium-appearance. Check the field names against your version of the menu.

Klesressursen er en vanlig addon-pakke, så alle menyer som leser addon-klær, viser den. For tatoveringer lager programmet lister for qb, esx og illenium-appearance. Sjekk feltnavnene mot din versjon av menyen.

Will it change my original files?Endrer det originalfilene mine?

No. Fix jobs work on a copy in the project folder, and anything in the way (an old build, for example) goes to the system trash. Nothing is deleted for good.

Nei. Fiksjobber jobber på en kopi i prosjektmappa, og alt som er i veien (for eksempel et gammelt bygg), havner i papirkurven. Ingenting slettes for godt.

My clothes do not show in gameKlærne vises ikke i spillet
  • Check the server's slot count and the subdir_file_mapping policy.
  • Make sure the resource is started (ensure) and the server's game build matches the one chosen on the Build tab.
  • Use Check an existing pack… on the Build tab to read the folder back.
  • Sjekk hvor mange plasser serveren har, og subdir_file_mapping-policyen.
  • Sjekk at ressursen er startet (ensure), og at serverens game build er den samme som du valgte på Bygg-fanen.
  • Bruk Check an existing pack… på Bygg-fanen for å lese mappa inn igjen.
Why does Windows warn about an unknown publisher?Hvorfor advarer Windows om ukjent utgiver?

The installer is not code-signed yet. See Install for how to get past SmartScreen.

Installeren er ikke kodesignert ennå. Se Installer for hvordan du kommer forbi SmartScreen.

Where do I get help?Hvor får jeg hjelp?

Spørsmål, feil og ideer tas i Unlimited Discord. Programmet har ingen e-postadresse.
